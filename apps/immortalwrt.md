## Overview

ImmortalWrt is an advanced, highly optimized fork of OpenWrt that addresses the primary pain points of official stock OpenWrt. Designed specifically for modern hardware, x86 mini PCs, and high-performance routers, ImmortalWrt provides vastly superior out-of-the-box package repositories, updated wireless drivers, and performance optimizations that make it far more capable than vanilla OpenWrt.

## Key Features

* **Massive Pre-Compiled Package Support:** Includes access to a significantly wider selection of pre-compiled packages directly via `opkg` that are missing or difficult to build on stock OpenWrt.
* **Modern Kernel & Driver Backports:** Ships with updated Linux kernels, enhanced hardware acceleration patches, and modern Realtek/Intel Ethernet drivers (e.g., r8125, r8152, igc).
* **Enhanced LuCI Web Interface:** Pre-styled with modern, responsive, touch-friendly themes and organized settings menus.
* **Out-of-the-Box Networking Tools:** Built-in support and optimized profiles for advanced routing, DNS encryption, Docker engine, samba file sharing, and hardware NAT offloading.
* **Wide Architecture Compatibility:** First-class support for x86/64 soft routers (like Lenovo Tiny M720q/M920q, Protectli, Topton), Raspberry Pi, NanoPi, and popular Wi-Fi 6 routers.
