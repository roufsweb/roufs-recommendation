## Overview

rootshell is a premier open-source, desktop-class terminal emulator and remote access suite for Apple platforms. Powered by libghostty with direct Metal GPU acceleration, it combines a blazing-fast local shell, native SSH with post-quantum cryptography, seamless Mosh-compatible roaming, tmux control mode, and full SSH VPN tunneling completely free without subscriptions or ads.

## Key Features

* **Metal GPU Acceleration:** Direct Metal rendering powered by libghostty's Zig engine delivers 120 FPS synchronized output, zero-flicker scrolling, and full mouse capture for tmux, vim, and zellij.
* **Native SSH & Post-Quantum Security:** High-performance Swift SSH engine supporting Ed25519, Secure Enclave biometric key storage, ML-KEM/ML-DSA post-quantum key exchange, jump hosts, and agent forwarding.
* **Rootshell Roam & tssh Protocols:** Mosh-compatible roaming that seamlessly survives Wi-Fi/cellular handoffs and sleep states, alongside QUIC and KCP transports for low-latency connections.
* **Native Tmux Control Mode:** Attach via `tmux -CC` to automatically convert remote tmux windows into native iOS tabs and splits with full touch and gesture support.
* **Built-in SSH VPN Tunneling:** Route full device network traffic through any remote SSH server with zero server-side daemon setup required.
* **Sandboxed Local Shell & Git:** Built-in local shell with curl, jq, vim, and native Git client on iOS/iPadOS, and full local shell execution on macOS.
