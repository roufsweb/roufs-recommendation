# Contributing to Rouf's Recommendations

Thank you for considering contributing to **Rouf's Recommendations**! Community recommendations help build the ultimate directory of high-utility tools, apps, and services.

## How to Contribute

### 1. Suggest a Recommendation (No Git Required)
If you know an awesome app, tool, or utility:
- Go to the [Issues tab](https://github.com/roufsweb/roufs-recommendation/issues).
- Click **New Issue**.
- Fill out the recommendation details.

### 2. Submit a Pull Request
If you are comfortable with Git:
1. **Fork** the repository to your GitHub account.
2. **Clone** your fork locally.
3. **Create a branch** for your addition (`git checkout -b add-my-recommendation`).
4. **Update `README.md`**: Find the appropriate section/category and add your recommendation using the standard format.
5. **Commit & Push** your changes.
6. **Open a Pull Request** against the `main` branch.

## Submission Guidelines

- ✅ **Trustworthy Sources Only**: App Store links (`apps.apple.com`), official GitHub releases, F-Droid, or verified official websites.
- ✅ **Free or High-Value Freemium**: Primary utility must be accessible without forced paywalls or deceptive subscriptions.
- ✅ **Clean & Safe**: No malware, ad-injecting shady wrappers, or broken software.
- ✅ **Alphabetical Order**: Place additions in alphabetical order within their subsection.

## Standard Entry Format

```markdown
- [Name](https://link-to-app-or-tool) - Concise 1-2 sentence description explaining what it does and why it is great. *(Pricing / Platform)*
```

Thank you for helping make this directory awesome!
