# Contributing to Rouf's Recommendations

Thank you for considering contributing to **Rouf's Recommendations**. Community contributions help build a trusted directory of high-utility tools, applications, and services.

## How to Contribute

### 1. Suggest a Recommendation (No Git Required)
If you know an exceptional app, tool, or utility:
* Navigate to the [Issues tab](https://github.com/roufsweb/roufs-recommendation/issues).
* Click **New Issue**.
* Provide the name, platform, pricing tier, and why you recommend it.

### 2. Submit a Pull Request
If you are comfortable with Git:
1. **Fork** the repository to your personal GitHub account.
2. **Clone** your fork locally.
3. **Create a branch** for your addition (`git checkout -b add-my-recommendation`).
4. **Update `README.md`**: Locate the appropriate section/category and add your recommendation using the standard table or list format.
5. If adding a dedicated profile card, add a corresponding markdown file in the `apps/` directory.
6. **Commit & Push** your changes.
7. **Open a Pull Request** against the `main` branch.

## Submission Standards

* **Trustworthy Sources Only:** Official Apple App Store links (`apps.apple.com`), official GitHub releases, F-Droid repositories, or verified developer domains.
* **Free or High-Value Freemium:** Core utility must be accessible without forced paywalls, aggressive watermarks, or deceptive subscription popups.
* **Security & Cleanliness:** Strictly no pirated bundles, malware, ad-injecting wrappers, or abandoned software.
* **Zero Emojis:** Do not include Unicode emojis in descriptions, table cells, or headings. Maintain clean typography and official icons.
* **Alphabetical Order:** Place additions in alphabetical order within their respective subsections.

## Standard Entry Format

```markdown
- [Name](https://link-to-app-or-tool) - Concise 1-2 sentence description explaining what it does and why it is great. *(Pricing / Platform)*
```

Thank you for helping curate this directory.
