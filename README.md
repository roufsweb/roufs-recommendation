### 🛠️ Guide: System-Wide Ad-Free iOS Setup

Pairing video and music streaming apps with a privacy-filtering DNS profile blocks in-app banner ads and video telemetry without draining your battery:

1. Install [DNSecure](https://apps.apple.com/us/app/dnsecure/id1533413232).
2. Configure **AdGuard DNS** using either DNS-over-HTTPS or standard IPs:
   * **Primary DNS:** `94.140.14.14`
   * **Secondary DNS:** `94.140.15.15`
   * **DoH URL:** `https://dns.adguard-dns.com/dns-query`
3. Toggle the profile on in iOS Settings. Enjoy uninterrupted playback and cleaner browsing.
