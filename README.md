## Technical Setup & Configuration Guides

### Guide A: System-Wide Ad-Free iOS Setup via Encrypted DNS

To suppress in-app commercials, telemetry trackers, and web banners across iOS without battery drain:

1. Install [DNSecure](https://apps.apple.com/us/app/dnsecure/id1533413232) from the App Store.
2. Tap the plus icon and select **DNS-over-HTTPS**.
3. Enter the official AdGuard DNS endpoint:
   ```text
   https://dns.adguard-dns.com/dns-query
   ```
4. Save the configuration and open **iOS Settings -> General -> VPN & Device Management -> DNS**.
5. Select **DNSecure**. All DNS queries are now filtered at the operating system layer.

---

### Guide B: Cloudflare Zero Trust Team Setup for Free Unlimited VPN

To unlock uncapped WireGuard VPN routing via Cloudflare's enterprise edge network:

1. Sign up for a free account at the [Cloudflare Zero Trust Dashboard](https://one.dash.cloudflare.com).
2. Choose your free team domain name (e.g., `yourname.cloudflareaccess.com`) on the Free 50-user plan.
3. Navigate to **Settings -> WARP Client -> Device enrollment rules** and add an allowed email rule (e.g., your personal email).
4. Download the **1.1.1.1: Faster Internet** app on your device.
5. In the app, open **Settings -> Account -> Login with Cloudflare Zero Trust**, enter your team domain, and authenticate via email PIN.
6. Toggle the connection switch to enable unlimited, high-speed encrypted VPN routing.

---

### Guide C: Twingate Homelab Setup (Zero Open Router Ports)

To access your internal home network services securely without opening router ports:

1. Create a free starter account at [Twingate](https://www.twingate.com).
2. Create a Remote Network labeled **Home Network** and add a **Connector**.
3. Deploy the connector on any always-on home device (Raspberry Pi, mini PC, NAS) using a single Docker run command:
   ```bash
   docker run -d --sysctl net.ipv4.ping_group_range="0 2147483647" \
     --env TENANT_URL="https://yournetwork.twingate.com" \
     --env ACCESS_TOKEN="your_connector_access_token" \
     --env REFRESH_TOKEN="your_connector_refresh_token" \
     --name twingate-connector \
     --restart unless-stopped \
     twingate/connector:latest
   ```
4. Define internal resources (e.g., `192.168.1.100` or `homelab.local`).
5. Install the Twingate client app on your phone or laptop. Connect with one click from anywhere in the world.
